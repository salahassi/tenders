The minimum corrective contract should preserve immutable raw source text and govern typed obligation units. It should pin predecessor and replacement review revisions, complete tuples, exact source provenance, authority/extraction versions and current supersession edges. New planning inventories should include exact current reviewed units. A machine row can be retired only when it unambiguously denotes one exact retired reviewed unit; record an auditable disposition. Do not delete a whole source chunk or infer semantic equivalence from filenames, dates, precedence numbers or numeric similarities. Partial tuples, paraphrases, shared evidence and mixed units need scoped repair or an explicit unresolved source review, preserving all original evidence. SQL persistence and issuance/export must independently enforce the resolution for pending/null-review rows and invalidate changed/revoked relationships. Historical snapshots and paid receipts must remain unchanged.

Blind text-range subtraction is unsafe: a reviewed span may contain the terminal-9 unit and an unrelated cabinet-3 clause even when the review tuple describes only terminals. A review's source span is evidence, not a universal attestation that every word in it is replaced. Multi-span reviews, shared spans, chains, revision changes, revoked replacements and overlapping active reviews require explicit controls.

The current quantity check tests the presence of values and units, not every obligation expressed by prose.
